System Architecture & AI Roadmap

Honest, secure foundations: why MindVault MVP operates 100% in-browser, and how the future AI backend will be safely connected.

Two-Tier Security & Storage Architecture

Directly embedding AI API keys (such as OpenAI, Anthropic, or Google Gemini) into client-side browser code leaks secrets to any visitor or script. MindVault strictly isolates all future AI functionality behind an authenticated first-party backend proxy.

Phase 1: Local Browser Engine Currently Active
  • ✔ 100% Client-side execution in current browser profile
  • ✔ Plaintext Web LocalStorage persistence with defensive parsing
  • ✔ Rule-based local smart search ("ideas about...", "tag:")
  • ✔ Deterministic daily insight seeded by local date
  • ✔ Grounded local retrieval Q&A with strict citations
  • ✔ Zero external API requests; zero credential leak risk
Phase 2: Secure Server Backend Planned Roadmap
  • ✦ Secure backend proxy (Node / Python / PHP)
  • ✦ Provider API keys stored in server environment variables
  • ✦ User authentication & encrypted cloud vault storage
  • ✦ Vector embeddings and semantic hybrid search
  • ✦ Automated LLM summarization and intelligent auto-tagging
  • ✦ Rate limiting, usage quotas, and prompt-injection safeguards
Honest Privacy & Storage Notice: MindVault runs completely on-device without sending your data to any cloud service.
• Unencrypted Storage: Web LocalStorage is stored as plain text within your browser profile. Anyone with physical access to your device profile can inspect this data. Do not store sensitive credentials in this release.
• Cache Deletion Warning: Clearing your browser cookies or site data will permanently remove your vault. Download regular backups via Settings → Export Vault as JSON.
